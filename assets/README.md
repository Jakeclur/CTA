# assets

Stage 1 generates every texture, model and sign in code (see `src/textures.js`, `src/world.js` and `src/vehicles.js`), so this folder is empty for now.

Later stages will put original or properly licensed audio and images here. Load them with relative paths such as `assets/audio/engine.ogg` so they work on GitHub Pages, and always include a fallback in case a file fails to load.
